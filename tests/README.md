# הבדיקות

74 חבילות שמריצות את האפליקציה האמיתית בדפדפן אמיתי. אין כאן מוקים
ואין הדמיה של הדפדפן: הבדיקה נכנסת עם שם משתמש וסיסמה, פותחת לקוח,
בונה פרויקט, גוררת ארגז על קיר, וקוראת את מה שבאמת מצויר על המסך.

זו הייתה החלטה ולא נוחות. אפליקציה שכל כולה גרירה, מדידה וציור אינה
נבדקת בפונקציות: באג ש"הארגז נשבר בזווית 135" אינו קיים בשום פונקציה
בודדת — הוא קיים בתמונה.

## הרצה

```sh
npm run dev        # בחלון אחד
npm test           # בחלון שני
```

חבילה בודדת:

```sh
node tests/l98.mjs
```

## מה צריך

- **Playwright** — `npm install` מתקין אותו.
- **דפדפן Chromium.** ברירת המחדל היא הנתיב של סביבת הפיתוח שבה נכתבו
  הבדיקות. במקום אחר:
  ```sh
  npx playwright install chromium
  CHROME_PATH=/path/to/chrome npm test
  ```
- **שרת פיתוח על 5173.** `_all.sh` בודק אותו ומסרב לרוץ בלעדיו, כי
  74 חבילות שנופלות על "אין שרת" אינן דוח בדיקות.

## מה יש כאן

| קובץ | מה |
|---|---|
| `mk.mjs` | העוזר המשותף: כניסה, לקוח, פרויקט עם קיר, והוספת ארגז |
| `l<מספר>.mjs` | חבילה לכל שכבת עבודה — `l98` היא הגיבוי, `l84` הספרייה |
| `_scene`, `_paint`, `_angles`, `_render` | מנוע הציור: פאות, סדר, וזוויות |
| `_ray` | מבחן הקרן — ראה למטה |
| `_plan` | התכנון האוטומטי: שההצעות לא מתנגשות בקירות |
| `_smoke` | הקובץ הבודד הבנוי, נטען מהדיסק בלי שרת |

צילומי המסך נשמרים ב-`tests/shots/` ואינם נשמרים בגיט — הם נוצרים
מחדש בכל הרצה.

## מבחן הקרן

`_ray.mjs` הוא הבדיקה שתופסת את מה שהעין מפספסת. לכל נקודה על המסך
הוא שואל שתי שאלות בנפרד: איזה לוח קרן מהמצלמה פוגשת ראשון, ואיזה
לוח צויר אחרון באותה נקודה. אם התשובות נבדלות — משהו מצויר מעל משהו
שאמור להסתיר אותו.

272 אלף נקודות, בכל זווית נגישה ובכל קיר פעיל. ככה נתפס שסדר הציור
נשבר בדיוק ב-45 ו-135 מעלות: שם ציר שלם ניצב לקו המבט, והפרדה עליו
אומרת "זה לצד זה" ולא "זה לפני זה". באמצע טווח המבט הרגיל, והעין לא
ראתה את זה.

## למה לא vitest

אין מריץ בדיקות. כל חבילה היא סקריפט node שמדפיס `PASS` / `FAIL`
ומסכם, ו-`_all.sh` מריץ את כולן. מודולי TypeScript נבדקים דרך
`await import('/src/...ts?v=' + Date.now())` בתוך הדפדפן — שרת
הפיתוח של Vite מקמפל אותם, ולכן אין צורך בשרשרת בנייה שנייה רק
לבדיקות.
